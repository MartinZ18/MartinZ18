Cómo trabajo

Escribo tests para lo que hago (Playwright, pytest); en Amicana eso significó pasar de "funciona en mi máquina" a una suite de regresión real.
Cuando integro un LLM en un flujo, siempre dejo un camino de manejo de errores — un JSON mal formado no debería tirar abajo todo el proceso.
